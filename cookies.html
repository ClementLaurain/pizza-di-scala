Politique de cookies

Résumé

Ce site est une vitrine. Nous n'avons détecté aucun traceur analytique (Google Analytics, Matomo) ni pixel publicitaire. Cependant, le site charge des ressources externes (polices Google Fonts, images depuis un CDN tiers). Ces requêtes externes transmettent des données techniques (adresse IP, user‑agent) au fournisseur tiers mais n'installent pas nécessairement des cookies depuis le code du site.

Traceurs identifiés

  • Google Fonts — fonts.googleapis.com (polices). Finalité : affichage des polices. Type : requête tierce, pas de cookie identifié dans le code. Verdict : pas de consentement requis, mais vous pouvez héberger les polices localement pour limiter les transferts.
  • CDN d'images — cdn.website.dish.co. Finalité : servir des images (logo). Type : requête tierce. Verdict : pas de cookie identifié; recommandation : héberger localement les images importantes.
  • Réseaux sociaux (Facebook, Instagram) — liens externes. Finalité : navigation vers les pages sociales. Pas de scripts/pixels détectés ici.

Décision recommandée

Comme aucun traceur non‑nécessaire n'est chargé automatiquement, nous ne mettons PAS en place de bandeau de consentement pour l'instant. Recommandations opérationnelles :

  • Héberger localement les polices Google Fonts.
  • Héberger les images actuellement servies depuis des CDNs externes dans le dépôt (ou sur un hébergeur européen).
  • Ne pas ajouter de scripts tiers (analytics, pixels) sans mettre en place un consentement explicite.

Si vous décidez d'ajouter Google Analytics, Facebook Pixel, YouTube embeds ou autres traceurs, il faudra mettre en place un bandeau de consentement et bloquer ces scripts avant acceptation.
